관리자 가이드

삼국지 천하결전 동맹 봇 · 서버 관리자용

1. 처음 시작하기

  1. 봇 초대·권한: 채널 관리 · 역할 관리 · 별명 관리 권한이 필요합니다. 봇 역할은 동맹원 · 간부 · 외교관 역할보다 위에 둡니다.
  2. 동맹 등록: /동맹등록으로 서버 번호(숫자)와 동맹명을 신청합니다. 제작자가 승인하면 역할과 #인증 채널이 자동으로 만들어집니다. 등록은 한 번만, 이후 수정은 /동맹수정입니다.
  3. 명단 올리기: 게임 명단 엑셀(.xlsx)을 /명단업데이트로 올립니다. (게임 엑셀은 매일 오전 8시 갱신) 명단에서 빠진 사람은 자동으로 이탈자로 옮겨집니다.
  4. 인증 안내: 동맹원은 #인증 채널에서 /인증으로 CID를 인증합니다. 인증하면 [직책]닉네임 별명과 역할이 부여됩니다. (5회 실패 시 잠김)

2. 관리 페이지 — /관리

관리자만 사용 · 나에게만 보이는 링크(6시간 유효, 공유 금지) · 저장 즉시 DB 반영, 4초마다 자동 갱신

탭기능
톡방 참여자추가 · 삭제 · 이름 수정. 명단에 없는 이름은 ⚠️ 표시
동맹원 추가게임 엑셀에 아직 없는 사람을 CID·닉네임으로 직접 추가 (엑셀 반영 전 3일 유지)
부캐본캐를 고르고 부캐 닉네임을 쉼표로 입력 → 명단과 대조해 연결. 오타·없는 닉네임은 제외하고 이유 안내
관리자 권한디스코드 사용자 ID로 공동관리자 추가/제거. 본인·제작자 권한은 뺄 수 없음
명령어 권한역할별 명령어 표 + 간부 명령어를 직책별로 제한 (직책 선택, 전체 = 간부 전체 허용)
인증 횟수 제한실패가 쌓인 계정·잠긴 계정 조회, CID 또는 디스코드 ID로 초기화

3. 권한 구조

역할사용 가능한 명령어
동맹원/인증 /부캐 /도감 /추천덱 /후원 /명령어
간부위 + /인사 /공성등록 /공성 /공성취소 /공성예약 /공성예약취소 /정철설정 /동맹수정 /동맹원추가 (직책별 제한 가능)
관리자위 전부 + /관리 /인증해제 /명단업데이트 /명단새로고침 /외교관해제 · /부캐의 본캐 지정
  • 제한에 걸리면 "권한이 없습니다."가 표시됩니다. 관리자는 제한과 관계없이 항상 사용할 수 있습니다.
  • 관리자 = 디스코드 서버 관리자 권한 보유자, 또는 /관리에서 부여받은 사람. 공동관리자는 관리자가 직접 추가합니다.

4. 봇이 만드는 채널

#관리자가이드채널 목록 최상단 · 관리자·봇만 열람 · 관리자 가이드 PDF 게시(내용이 바뀌면 자동 교체)
#이용자가이드채널 목록 최상단 · 모두 읽기 전용 · 동맹원용 이용 가이드 PDF 게시
#인증신규 인원이 CID 인증을 하는 채널
#명령어로그최하단 "봇" 카테고리 · 관리자·봇만 열람 · 모든 명령어 사용 기록(시각·명령어·옵션·사용자)
#후원최하단 "봇" 카테고리 · 후원 안내를 서버마다 한 번 게시

5. 자주 겪는 문제

채널·역할이 안 만들어짐봇 역할에 채널 관리·역할 관리 권한 확인. 아래 초대 링크를 다시 열어 승인하면 권한만 갱신됩니다.
discord.com/oauth2/authorize?client_id=1563493671473520740&permissions=2550254672&scope=bot+applications.commands
인증이 잠김/관리 → 인증 횟수 제한에서 초기화, 또는 /인증해제
CID가 명단에 없음오타 확인 후, 신규 가입자는 관리 페이지 → 동맹원 추가로 먼저 등록
링크 만료/관리 · /인사를 다시 입력하면 새 링크 발급
부계정이 여럿관리 페이지 → 부캐에서 본캐에 연결
⚠️ 봇 토큰(DISCORD_TOKEN)과 관리 링크는 절대 공유하지 마세요. 초대 링크는 공개해도 안전합니다. 승인되지 않은 서버에서는 /동맹등록만 사용할 수 있습니다.
